# Honorebi 1.1.7

1.1.6 からの修正アップデートです。build 33（versionCode 33）。

## 修正

- 録画一覧と SMB ファイル一覧で、画面下部に大きな空白が残り、表示できる範囲が狭くなる問題を修正しました。リスト・グリッド・シリーズ・検索結果に反映されます。
- 読み込み中やエラー時の案内は必要なときだけ表示し、通常時は一覧の領域を確保するようにしました。

## 配布 APK

- `app-arm64-v8a-release.apk`: 64bit Android 向け
- `app-armeabi-v7a-release.apk`: 32bit Android 向け
- `app-universal-release.apk`: 汎用版・旧 OTA クライアント向け
