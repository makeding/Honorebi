# Honorebi 1.1.6

1.1.5 からの修正アップデートです。build 32（versionCode 32）。

## 修正・改善

- サーバー接続エラーの理由を画面内に表示し、長いエラー内容はリモコンでその場でスクロールできるようにしました。接続設定への導線とフォーカス復帰も整理しています。
- オフライン案内とホーム画面のエラー表示で、保存済み情報を残したまま状態を確認できるようにしました。
- 古い Android TV で再生画面を開いた際にクラッシュする問題を修正しました。音声フォーカス処理と Cast ルート検出で、新しい Android API が未対応端末で読み込まれないようにしています。
- 再生終了時の後処理と、リモコン操作時のフォーカス処理を改善しました。

## 配布 APK

- `app-arm64-v8a-release.apk`: 64bit Android向け
- `app-armeabi-v7a-release.apk`: 32bit Android向け
- `app-universal-release.apk`: 汎用版・旧OTAクライアント向け
