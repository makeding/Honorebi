## 安全修复

- **修复 libaribcaption 上游 CVE-2026-112284：B24 转换表可能导致的越界读取。** 对应上游提交：[e7d24523](https://github.com/makeding/libaribcaption/commit/e7d24523c1db421a20093999051625ba3552de8a)。

## 依赖更新

- libaribcaption 更新到 `d9da25a`，包含 Android 字幕渲染崩溃、语言变更后的字体重载、缺字区域处理和换行时机等上游修正。
- Media3 从 `1.11.0-komorebi6` 更新到 `1.11.1-komorebi7`；六个 Komorebi 广播播放补丁均在上游 1.11.1 提交上重放并重新构建。
- libaribtlv 更新到 `f4a603b`。tlvdemux 固定在已推送的 `9bec5f8`，Komorebi 保留该 A/V recovery 改动。
- Android 更新到 AGP `9.5.1`、Gradle `9.9.0`、DataStore `1.3.0`、OkHttp `5.5.1` 和 Ktor `3.6.1`；Web 与 Nix 开发环境依赖同步更新。
