# Honorebi 1.1.8

1.1.7 からの更新です。build 34（versionCode 34）。

## 修正・改善

- **セキュリティ修正: libaribcaption の [CVE-2026-112284](https://github.com/makeding/libaribcaption/commit/e7d24523c1db421a20093999051625ba3552de8a) に関する範囲外読み取りを修正しました。**
- 字幕描画ライブラリ libaribcaption を更新し、字幕言語の切り替え、文字の折り返し、Android の描画クラッシュに関する上流修正を取り込みました。
- Media3 を 1.11.1 に更新し、放送向けのローカル修正を維持しています。
- アプリ起動時とテレビのスリープ復帰時に更新情報を確認します。ダウンロードとインストールは従来どおり確認後に開始します。
- Android、Web、Nix 開発環境の依存ライブラリを更新しました。

## 配布 APK

- `app-arm64-v8a-release.apk`: 64bit Android 向け
- `app-armeabi-v7a-release.apk`: 32bit Android 向け
- `app-universal-release.apk`: 汎用版・旧 OTA クライアント向け
