# Honorebi 1.1.2 beta6

versionCode: **27** / versionName: **1.1.2-beta6-huggy**

- ライブと録画のプレイヤー表示を共通化しました。ライブの進行バーは番組の経過時間と総時間を表示し、EPG がある場合は左上に終了予定時刻を表示します。
- ライブの上下キーは、最初に操作画面を表示し、もう一度押すと選局画面やメニューを開きます。選局画面の準備は操作画面の表示後に行います。
- ライブでは一時停止・シークを行わず、録画のサムネイル選択に相当する位置から素早く選局できます。
- 設定画面を開いているときにリモート再生を受け付けると、設定画面を閉じてプレイヤーを前面に表示します。
- ライブ視聴履歴の同期に対応しました。対応する HonomiTV サーバーが必要です。
